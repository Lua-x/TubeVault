For every device and every media server: TubeVault now plays everywhere, works together with Jellyfin, Emby, Kodi and Plex, and gets an admin area.

### New

- **Playback on every device**: the player checks what the browser can do. If only the container doesn't fit (e.g. MKV on an iPhone), the file is remuxed to MP4 once – in seconds and without quality loss. If the codec doesn't fit or you pick a lower quality, TubeVault transcodes while you watch (HLS). Seeking works, and ffmpeg only runs while someone watches
- **Quality picker in the player** (⚙︎ at the top right): automatic, 1080p, 720p, 480p, 360p – remembered per device
- **Hardware transcoding** with Intel/AMD (VAAPI) or NVIDIA (NVENC), with a test button in the settings and an automatic fallback to software. The image now ships jellyfin-ffmpeg for this
- **Jellyfin, Emby, Kodi, Plex**: NFO files for every video (also afterwards for the existing library) and an optional **series layout** – every channel a show, every year a season, with `tvshow.nfo` and a background image. Switching moves the whole library, thumbnails and subtitles included
- **Import existing videos** from `/import` or unknown files under `/media`, e.g. an old yt-dlp archive. The YouTube ID comes from the `.info.json` or the file name; move, copy or leave in place
- **Verwaltung** (admin area, for admins): key figures, storage per channel, downloads of the last 30 days, system information, log and maintenance (verify files, search index, channel art, NFOs, cache)
- **yt-dlp update at the push of a button**, including a restart of TubeVault right from the interface
- **API tokens** for scripts and shortcuts (read-only or full access, with an expiry date) – the README shows an iPhone shortcut "Share → Load into TubeVault"
- **Share target on Android**: with TubeVault installed as an app, shared YouTube links land directly in the "add video" dialog
- **License**: TubeVault is now licensed under the AGPL-3.0

### Improved

- An older image can no longer damage a newer database: TubeVault then refuses to start and says clearly why
- `latest` always points to the current release; older versions built later no longer move it
- The Docker build checks the image before publishing it (encoders, start, health check)

### Upgrade notes

- The database is migrated automatically on start (API tokens). Afterwards TubeVault writes NFO files for the existing videos once; this can be turned off under **Einstellungen → Mediaserver**.
- The image got a bit bigger because of jellyfin-ffmpeg.
- For hardware transcoding, pass the GPU through – the compose examples are in the README under "hardware acceleration".
- New optional volume `/import` for importing.

```sh
docker compose pull && docker compose up -d
```
