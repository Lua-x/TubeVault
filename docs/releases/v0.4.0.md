Für jedes Gerät und jeden Mediaserver: TubeVault spielt jetzt überall ab, arbeitet mit Jellyfin, Emby, Kodi und Plex zusammen und bekommt eine Verwaltung.

### Neu

- **Wiedergabe auf jedem Gerät**: Der Player prüft, was der Browser kann. Passt nur der Container nicht (z. B. MKV auf dem iPhone), wird einmalig in MP4 umverpackt – in Sekunden und ohne Qualitätsverlust. Passt der Codec nicht oder wählst du eine kleinere Qualität, wandelt TubeVault beim Abspielen um (HLS). Spulen funktioniert, ffmpeg läuft nur, solange jemand schaut
- **Qualitätswahl im Player** (⚙︎ oben rechts): Automatisch, 1080p, 720p, 480p, 360p – pro Gerät gemerkt
- **Hardware-Transcoding** mit Intel/AMD (VAAPI) oder NVIDIA (NVENC), mit Test-Knopf in den Einstellungen und automatischem Rückfall auf Software. Das Image enthält dafür jetzt jellyfin-ffmpeg
- **Jellyfin, Emby, Kodi, Plex**: NFO-Dateien für jedes Video (auch nachträglich für die vorhandene Bibliothek) und wahlweise ein **Serien-Schema** – jeder Kanal eine Serie, jedes Jahr eine Staffel, mit `tvshow.nfo` und Hintergrundbild. Beim Umschalten zieht TubeVault die Bibliothek samt Thumbnails und Untertiteln um
- **Import vorhandener Videos** aus `/import` oder unbekannten Dateien unter `/media`, z. B. ein altes yt-dlp-Archiv. Die YouTube-ID kommt aus der `.info.json` oder dem Dateinamen; Verschieben, Kopieren oder Liegenlassen
- **Verwaltung** (für Admins): Kennzahlen, Speicher pro Kanal, Downloads der letzten 30 Tage, Systeminfos, Protokoll und Wartung (Dateien prüfen, Suchindex, Kanalbilder, NFOs, Cache)
- **yt-dlp-Update auf Knopfdruck** samt Neustart von TubeVault direkt aus der Oberfläche
- **API-Tokens** für Skripte und Kurzbefehle („Nur lesen“ oder „Voller Zugriff“, mit Ablaufdatum) – die README zeigt einen iPhone-Kurzbefehl „Teilen → In TubeVault laden“
- **Teilen-Ziel auf Android**: Ist TubeVault als App installiert, landen geteilte YouTube-Links direkt im Dialog „Video hinzufügen“
- **Lizenz**: TubeVault steht jetzt unter der AGPL-3.0

### Verbessert

- Ein älteres Image kann eine neuere Datenbank nicht mehr beschädigen: TubeVault startet dann nicht und sagt klar, warum
- `latest` zeigt immer auf den aktuellen Stand; nachträglich gebaute ältere Versionen verschieben es nicht mehr
- Der Docker-Build prüft das Image vor dem Veröffentlichen (Encoder, Start, Healthcheck)

### Hinweise zum Update

- Die Datenbank wird beim Start automatisch migriert (API-Tokens). Danach schreibt TubeVault einmalig NFO-Dateien für die vorhandenen Videos; abschalten lässt sich das unter **Einstellungen → Mediaserver**.
- Das Image ist durch jellyfin-ffmpeg etwas größer geworden.
- Für Hardware-Transcoding die GPU freigeben – die Compose-Beispiele stehen in der README unter „Hardware-Beschleunigung“.
- Optionales neues Volume `/import` für den Import.

```sh
docker compose pull && docker compose up -d
```
