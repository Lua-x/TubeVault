Offline, safe, automatic: TubeVault keeps working without internet, backs itself up, finds new videos faster and tells you when something happens.

### New

- **Without internet**: library, search and playback only need your server. Downloads now wait for the connection instead of failing for good after five attempts, and start by themselves once the network is back. Subscription checks, channel art and SponsorBlock are postponed quietly, the video page no longer waits for SponsorBlock, and the container starts right away without network. The downloads page shows when YouTube can't be reached
- **Backups** (**Verwaltung → Sicherung**): daily and automatic to `/config/backups` (the last 7 are kept), at the push of a button, as a ZIP to download – and restore from the list or from a file. The state before a restore is backed up as well
- **New videos sooner**: every 15 minutes a look at each subscription's RSS feed; the thorough check only runs early when there are unknown videos
- **Fetch better quality**: if YouTube only had a low resolution shortly after the upload, TubeVault replaces the file with the better version within the first 7 days – watch progress and playlists stay. Admins can fetch any video again with "Neu laden" (reload)
- **Notifications** to your own ntfy or Gotify server or a webhook: new videos, errors, low disk space, yt-dlp updates. Several events arrive as one message
- **Large libraries**: library, channel pages and search load more while you scroll instead of stopping at 200 videos. Search no longer stops at 1000 results and counts correctly – tested with 10,000 videos, every query under 0.2 seconds

### Improved

- A subscription's clean-up rules delete videos, so only admins can change them now
- A Content Security Policy makes sure the interface loads nothing from outside
- Dependabot suggests updates for backend, frontend and GitHub Actions
- "Verify files" runs automatically after a restore

### Upgrade notes

- No database migration needed. On first start TubeVault creates its first automatic backup.
- The RSS check and fetching better quality are on, notifications are off – everything under **Einstellungen → Automatik** and **Verwaltung**.

```sh
docker compose pull && docker compose up -d
```
