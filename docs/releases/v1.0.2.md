The best available quality by default – the same streams as Pinchflat's highest profile – and settings that are saved the moment you change them.

### New

- **Best available quality by default**: new downloads come in the highest resolution YouTube has, 4K or even 8K. **Maximale Qualität** (maximum quality) still sets a limit when you want to save space. Installs still on the old default (1080p) move to "Beste verfügbare" (best available); a limit you chose yourself stays, and so do the subscriptions' own limits
- **The same choice as Pinchflat, tested**: for every Pinchflat profile a test runs yt-dlp's own format selection with Pinchflat's options and with TubeVault's, and checks that both take the very same streams – the same file, the same size. "Beste verfügbare" matches Pinchflat's 4320p profile, "4K (2160p)" its 2160p profile, and so on
- **"Video hinzufügen" (add video) remembers its options** – quality, format and comments – for your account on every device. While collapsed, **Optionen** shows what is set

### Fixed

- **Settings are saved right away**: under **Einstellungen** (settings), changes to downloads, automation, subtitles, transcoding, analysis, library and DLNA waited for a "Speichern" (save) button at the very bottom of a long page – leaving the page dropped them without a word. Now every change is saved by itself; text fields when you leave them or press Enter. Moving the library to another folder layout still asks first
- A video's resolution is named after the shorter side: a Short in 1080×1920 shows 1080p instead of 1440p

### Upgrade notes

- One database migration (0014) runs by itself on start. As always, back up under **Verwaltung → Sicherung** first – going back to 1.0.1 isn't possible afterwards.
- Videos already in your library stay as they are. **Neu laden** (reload) on a video's page fetches it again in the best quality; watch progress and playlists stay. What a video was downloaded in is listed under **Details** on its page.
- Videos above 1080p are several times larger than the 1080p H.264 file and come as VP9 or AV1. Older iPhones and some TVs get them converted while watching.
