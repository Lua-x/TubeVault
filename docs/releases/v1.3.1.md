A small fix: subscribing with "all existing videos" takes all of them again.

### Fixed

- **"Vorhandene Videos: Alle" (existing videos: all) works**: a new subscription with this choice was stored as "the newest 5", so the first check downloaded five videos and skipped the rest as "Älter – beim Abonnieren übersprungen" (older – skipped when subscribing). Now it takes every video of the channel

### Upgrade notes

- No database migration; going back to 1.3.0 is possible.
- Subscriptions made with "Alle" before this version keep their skipped videos. To fetch them: delete the subscription under **Abo löschen** (delete subscription) without ticking "also delete the downloaded videos", then subscribe again with "Alle". Videos that are already in the library are linked, not downloaded again.

```sh
docker compose pull && docker compose up -d
```
