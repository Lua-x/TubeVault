The first version of TubeVault – the MVP.

### New

- **Add videos** by YouTube link; downloaded with yt-dlp and ffmpeg as MP4 (H.264 preferred) or MKV, in up to 4K
- **Metadata**: title, description, channel, upload date, thumbnail, chapters, subtitles (manual ones and automatic ones in the original language)
- **Download queue** with live progress over WebSocket, cancel, retry, and automatic retries with backoff on network errors and rate limits
- **Library** as a thumbnail grid with a hero, search and sorting
- **Player** (Video.js with its own skin): seeking via HTTP Range, chapters with markers, subtitles, keyboard shortcuts, picture-in-picture
- **Users**: set up in the browser or with `ADMIN_USER`/`ADMIN_PASSWORD`, several accounts, admin role
- **Design**: dark, light or system; a sidebar on desktop, a tab bar on phones
- **Docker**: one image for amd64 and arm64, `PUID`/`PGID`, health check, doesn't run as root, yt-dlp update on start, `BASE_PATH` for reverse proxies
- Folder layout that works with Jellyfin/Plex: `/media/<Channel>/<Year>/<Title> [<ID>].mp4`

### Installation

```yaml
services:
  tubevault:
    image: ghcr.io/lua-x/tubevault:0.1.0
    ports: ["8096:8096"]
    environment: [PUID=1000, PGID=1000, TZ=Europe/Berlin]
    volumes: [./config:/config, /path/to/videos:/media]
    restart: unless-stopped
```

Details in the [README](https://github.com/Lua-x/TubeVault#readme).
