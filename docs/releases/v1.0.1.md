Downloads in full quality, like Pinchflat – and a container that repairs the rights of its `config` folder instead of failing on start.

### Fixed

- **Download quality now works like in Pinchflat**: with "H.264 bevorzugen" (prefer H.264, on by default), TubeVault always took the 1080p H.264 stream – even with 4K or "Beste verfügbare" (best available) chosen, because YouTube offers H.264 only up to 1080p. Now the resolution comes first and H.264 only counts between formats of the same resolution, so 1440p and 4K arrive as VP9/AV1 in full quality, untouched
- **Shorts in full resolution**: the limit is measured on the shorter side, like Pinchflat does. Portrait videos used to fall back to 480p with a 1080p limit; now they come in 1080×1920
- **"Bessere Qualität nachladen"** (fetch better quality later) compares resolutions the same way and aims for up to 4K with "Beste verfügbare"
- **`PermissionError` on `/config` at start**: the container repairs the rights of its `config` folder by itself (e.g. after `chmod -R 644` or copying it with a tool that drops the "enter" right of folders); started with `user:`, it says what to run instead of failing with a traceback

### Upgrade notes

- No database migration; going back to 1.0.0 is possible.
- For the best quality, set **Einstellungen → Downloads → Maximale Qualität** to "Beste verfügbare" or "4K (2160p)" and leave subscriptions on "Standard". Videos above 1080p are larger and come as VP9/AV1, which older iPhones and some TVs get converted while watching.
- Videos already in your library stay as they are. **Neu laden** (reload) on a video's page fetches it again in the new quality; watch progress and playlists stay.

```sh
docker compose pull && docker compose up -d
```
