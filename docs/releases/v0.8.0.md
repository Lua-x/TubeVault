Living room and media server: send videos to the TV, a TV view for the remote, a DLNA server for the home network – and, if you like, TubeVault as a pure media server for your own videos, without YouTube at all.

### New

- **To the TV**: a button in the player sends the video to the TV via Chromecast (Chrome) or AirPlay (Safari) – using what the browser has built in, without a script from Google. The TV fetches the video through a signed link that is valid for 12 hours and opens only this video; MKV is remuxed to MP4 for it once
- **TV view**: big tiles, fully usable with the arrow keys of a remote – OK plays and pauses, left/right seeks, back goes back and lands on the tile you chose last. Smart TVs (Fire TV, Android TV, Tizen, webOS …) open it by themselves, otherwise under **Einstellungen → Darstellung** (settings → appearance) or `/tv`
- **DLNA server**: smart TVs, consoles, VLC and Kodi find TubeVault in the home network without an app – with "channels", "recently added" and "playlists", seeking included. Off by default, answers only devices from the home network, refuses everything that comes through a reverse proxy and shows only what the chosen account may see (e.g. a kids profile). Needs `network_mode: host` in Docker
- **Media server only**: under **Einstellungen → Betrieb** (settings → operation) the YouTube downloader can be turned off. Then no connection leaves the server any more – no subscriptions, downloads, comments, no SponsorBlock, no yt-dlp update – the app hides adding, subscriptions and downloads, and the clean-up rules pause. Turning it back on continues exactly where it stopped
- **Your own videos**: the import now also takes files without a YouTube ID, e.g. from a phone or camera. The folder becomes the channel (`/import/Holiday 2024/…` → "Holiday 2024"), title, description and recording date come from the file, and copies are recognised. Your own videos work everywhere – player, TV view, DLNA, playlists, podcasts, kids profiles

### Improved

- **Accessibility**: contrast meets WCAG AA in light and dark, a skip link that really jumps to the content, dialogs keep the focus and return it to the button that opened them, clean headings and landmarks. axe-core finds nothing on any of the 18 pages
- **Faster start**: settings, admin area, import, subscriptions and downloads only load when opened – the initial bundle shrinks from 184 to 106 KB (gzip)
- Measured with 10,000 videos: history, similar videos, search filters, comments (5,000 on one video), watch later and DLNA browsing answer in under 50 ms

### Security

- Remuxing, versions for "save to device" and audio tracks run at most two at a time – many requests at once could start any number of ffmpeg processes before
- Podcast addresses can only be created or renewed from a browser sign-in, no longer with an API token

### Upgrade notes

- No database migration this time; a backup under **Verwaltung → Sicherung** never hurts.
- For DLNA, set `network_mode: host` in `docker-compose.yml` (instead of `ports:`) and turn it on under **Einstellungen → Fernseher im Heimnetz** (settings → TVs in the home network).
- The colours got a little stronger: blue, red and the grey hint texts have more contrast.

docker compose pull && docker compose up -d
