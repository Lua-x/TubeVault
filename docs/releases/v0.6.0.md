Accounts and on the go: save videos to your phone and watch without the server, two-factor login, login through your own identity provider, and rights per user.

### New

- **Save to device** ("Aufs Gerät"): on the video page or for a whole playlist, videos are stored in the installed app – as the original or as a compact version in 720p or 480p that your server converts to H.264 once. The dialog estimates the size beforehand and shows the free space. Everything saved is listed under **Auf diesem Gerät** (on this device), with subtitles, chapters and thumbnail. If the server can't be reached, the app starts right there; where you stopped reaches the server later. Needs HTTPS, and the app has to stay open while saving – details and the limits on iPhone/iPad are in the README
- **Two-factor login** (**Einstellungen → Konto**, settings → account): scan the QR code with an authenticator app, and TubeVault asks for the code when you sign in. Ten recovery codes for emergencies; admins can reset a user's two-factor login, and there is `python -m app reset-2fa <user>`
- **Login through your identity provider** (OpenID Connect): Authelia, Authentik, Keycloak, Pocket ID and others – set up with environment variables (`OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, …). Unknown accounts are created on first login (can be turned off), members of `OIDC_ADMIN_GROUP` become admins. Existing accounts are linked in the settings; with `PASSWORD_LOGIN=false` only the provider is left
- **Rights per user** (**Einstellungen → Benutzer**, settings → users): see only selected channels – e.g. a kids profile that can't find anything else anywhere, not even by link – and watch-only accounts without adding, subscriptions and downloads

### Improved

- The app starts without the server too: interface and player are fully cached by the installed app
- Signing out shows the login page right away

### Upgrade notes

- The database is migrated automatically on first start (two-factor, rights, OIDC). As always, going back to 0.5 isn't possible afterwards – back up under **Verwaltung → Sicherung** first.
- All existing users keep seeing every channel and may add videos. OIDC stays off as long as `OIDC_ISSUER` is empty.

docker compose pull && docker compose up -d
