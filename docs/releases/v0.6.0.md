Konten & unterwegs: Videos aufs Handy laden und ohne Server schauen, Zwei-Faktor-Anmeldung, Login über deinen eigenen Anmeldedienst und Rechte pro Benutzer.

### Neu

- **Aufs Gerät laden**: Auf der Videoseite oder bei einer ganzen Playlist speichert „Aufs Gerät“ Videos in der installierten App – als Original oder als kompakte Fassung in 720p bzw. 480p, die dein Server einmal in H.264 umwandelt. Der Dialog schätzt die Größe vorher und zeigt den freien Speicher. Alles Gespeicherte steht unter **Auf diesem Gerät**, mit Untertiteln, Kapiteln und Vorschaubild. Ist der Server nicht erreichbar, startet die App direkt dort; wo du aufgehört hast, landet später auf dem Server. Braucht HTTPS, und die App muss beim Laden geöffnet bleiben – Details und die Grenzen auf iPhone/iPad stehen in der README
- **Zwei-Faktor-Anmeldung** (Einstellungen → Konto): QR-Code mit einer Authenticator-App scannen, danach fragt TubeVault beim Anmelden nach dem Code. Zehn Wiederherstellungscodes für den Notfall; Admins können die Zwei-Faktor-Anmeldung eines Benutzers zurücksetzen, außerdem gibt es `python -m app reset-2fa <benutzer>`
- **Login über deinen Anmeldedienst** (OpenID Connect): Authelia, Authentik, Keycloak, Pocket ID & Co. – eingerichtet über Umgebungsvariablen (`OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, …). Unbekannte Konten werden beim ersten Login angelegt (abschaltbar), Mitglieder von `OIDC_ADMIN_GROUP` werden Admins. Bestehende Konten verbindest du in den Einstellungen; mit `PASSWORD_LOGIN=false` geht es nur noch über den Anbieter
- **Rechte pro Benutzer** (Einstellungen → Benutzer): nur ausgewählte Kanäle sehen – etwa für ein Kinderprofil, das alles andere nirgends findet, auch nicht per Link – und „Nur schauen“-Konten ohne Hinzufügen, Abos und Downloads

### Verbessert

- Die App startet auch ohne Server: Oberfläche und Player liegen vollständig im Cache der installierten App
- Abmelden zeigt sofort wieder die Anmeldeseite

### Hinweise zum Update

- Die Datenbank wird beim ersten Start automatisch migriert (Zwei-Faktor, Rechte, OIDC). Wie immer gilt: Zurück auf 0.5 geht danach nicht mehr – vorher unter **Verwaltung → Sicherung** sichern.
- Alle bestehenden Benutzer sehen weiterhin alle Kanäle und dürfen Videos hinzufügen. OIDC ist aus, solange `OIDC_ISSUER` leer ist.

```sh
docker compose pull && docker compose up -d
```
